
# 🧑‍💻 Developer Portfolio

A personal developer portfolio built with Python to showcase projects, skills, and professional information.

## 🚀 Features

- Personal introduction and profile
- Skills and technologies showcase
- Project portfolio
- Contact information
- Clean and responsive web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Pillow

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/developer-portfolio.git
cd developer-portfolio
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it:

**Windows**
```bash
venv\Scripts\activate
```

**macOS / Linux**
```bash
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run main.py
```

The application will open in your browser.
